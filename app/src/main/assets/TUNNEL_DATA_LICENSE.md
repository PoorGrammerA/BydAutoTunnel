# Korea Road Tunnel Data License

This directory's `tunnels_kr.bin` and derived datasets are derived from the
South Korea OpenStreetMap extract supplied by Geofabrik.

Data © OpenStreetMap contributors, available under the Open Database License
(ODbL) 1.0: https://www.openstreetmap.org/copyright

The database is generated by filtering OpenStreetMap road extracts for `tunnel=yes`
ways and processing them with AutoTunnel build tools.
The tunnel geometric data is data, not software covered by this repository's Apache 2.0 license.
